# 🛡️ HTB Sherlock — Remote_Access_Regret

**Dificuldade:** Very Easy · **Categoria:** DFIR / Blue Team · **Artefatos:** Chrome History + cache, AnyDesk (config e logs)

---

## 📖 Cenário

Em 18/02/2025, Margaret pesquisava receitas quando o navegador abriu um aviso em tela cheia dizendo que o PC estava infectado. Ela ligou para o número exibido e um falso "Microsoft Support" a convenceu a instalar um programa de acesso remoto (AnyDesk). Depois de mais de uma hora de "limpeza", o golpista cobrou US$ 500 em gift cards.

É um golpe clássico de **tech support scam**: engenharia social, depois acesso remoto, depois roubo de arquivos e dinheiro. O trabalho é reconstruir a linha do tempo usando os dados do Chrome e do AnyDesk.

## 🧩 Artefatos e onde procurar

| Artefato | Local típico (Windows) | O que mostra |
|---|---|---|
| Chrome History (SQLite) | `Users\<user>\AppData\Local\Google\Chrome\User Data\Default\History` | URLs, visitas e timestamps |
| Chrome Cache | `...\Default\Cache\Cache_Data\` | cópias das páginas visitadas (HTML do golpe) |
| AnyDesk config | `AppData\Roaming\AnyDesk\system.conf` | ID local da máquina |
| AnyDesk logs | `AppData\Roaming\AnyDesk\ad.trace` / `connection_trace.txt` (ou em `ProgramData\AnyDesk\`) | conexões recebidas, ID remoto, alias, sessão, transferências |

## 🕵️ Investigação

### 1. ID local do AnyDesk (Task 0)
```bash
grep -i "id" system.conf
```
A linha `ad.anynet.id=` traz o ID da máquina da vítima: **847291503**.

### 2. Histórico do Chrome (Tasks 1, 2 e 9)
O `History` é um banco SQLite:
```bash
sqlite3 History "SELECT datetime(last_visit_time/1000000-11644473600,'unixepoch'), url, visit_count FROM urls ORDER BY last_visit_time;"
```
> O Chrome grava o tempo em microssegundos desde 1601. A conta acima converte para data legível.

- Primeiro site visitado antes do golpe: **www.google.com**
- Domínio do redirecionamento malicioso inicial: **ww1.windows-security-alert.com**
- Total de URLs visitadas na sessão do dia do incidente: **10**

### 3. Página do golpe em cache (Task 3)
```bash
grep -ril "microsoft\|call" Cache_Data/ 
strings <arquivo_de_cache> | grep -E "\+1 ?\(?[0-9]{3}"
```
O telefone exibido para a vítima era **+1 (888) 351-4019**.

### 4. Logs do AnyDesk (Tasks 4 a 8)
```bash
grep -iE "incoming|remote|alias|session|file" ad.trace connection_trace.txt
```
- ID AnyDesk da máquina do atacante: **529481627**
- Alias usado pelo golpista: **MicrosoftSupport**
- Duração total da sessão: **4052 segundos** (≈ 67 minutos, batendo com a "mais de uma hora" do relato)
- Primeiro arquivo exfiltrado da Área de Trabalho: **Bank Statements 2024.pdf**
- Total de bytes enviados ao atacante: **1559433** (≈ 1,5 MB)

## 🧠 Lições para SOC

- Pop-up de "vírus" com telefone é sempre golpe: a Microsoft não liga nem pede ligação.
- Ferramentas legítimas (AnyDesk, TeamViewer) são abusadas. Alertas de **instalação/execução de RMM não autorizado** valem ouro.
- O alias "MicrosoftSupport" não prova nada. O que identifica o atacante é o **ID remoto**.
- Cruzar navegador + app de acesso remoto reconstrói a história inteira: isca → contato → acesso → exfiltração.
